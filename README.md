One word your ex would use to describe you, entered for the make.fun bounty "One Word From Your Ex". The word is **Unforgettable**: it sounds like a compliment until you remember who is saying it. An ex calling you unforgettable is not flattering you, it is confessing that you ruined them for everyone else.

## Run it

```sh
python3 main.py
```

The program writes exactly one word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
